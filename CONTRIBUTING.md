# Kako Pridonijeti

Hvala što razmišljate da pridonijete GLJ projektu! 🎉

## Koraci

1. **Fork** projekta
2. Kreiraj novu granu (`git checkout -b feature/opis`)
3. Komituj promjene (`git commit -m 'Add opis'`)
4. Pushaj u granu (`git push origin feature/opis`)
5. Otvori Pull Request

## Pravila

- Prati kod standarde
- Piši jasne commit poruke
- Testiraj prije push-a

Hvala! ❤️
